How the money-visibility proof works

The question: can anybody see an amount they are not allowed to see — selling prices, buyer payments, purchase / supplier prices, logistics / CHA costs, costs and profit, incentives / associate commission, or the CA annexure (CAFIN)?

1. Unmistakable test amounts

The test creates one sample order in which every kind of money carries a unique amount that exists nowhere else in the system:

  • Selling price 917.43
  • Buyer payment 823.61
  • Purchase / supplier 731.29
  • Logistics / CHA 649.17
  • Costs, expenses, profit 557.83
  • Incentive / associate commission 461.39

It also creates each kind of file (supplier bill, logistics bill, expense receipt, payment screenshot, buyer PO, packing photo) and every generated document — the current copy and an old draft copy — plus audit-log rows carrying each amount.

2. Every role, every screen, every file

One login is made for every role in the system (23 roles). Each of them, in turn:

  • opens 71 screens in the Standard look and 12 in the Kanban look — order page, lists, dashboard, My tasks, cockpit, every report and its CSV export, audit logs, the CA module, suppliers, logistics partners, products, procurement, associates, incentives, help pages;
  • tries to download all 20 files of the order (current and old copies of every document, every uploaded file);
  • downloads the order's dossier ZIP and checks which files are inside.

3. The rule checked

A test amount may appear — and a file may download — only for a role that holds the matching permission (see role_permissions.html). Anything else is counted as a violation.

4. Result

0 violations means no role saw a single amount or file it is not allowed to see, on any screen, export, download or ZIP. The two matrix reports show, role by role, which kinds of money each one saw ("seen") or did not ("hidden"), so you can also check that each role does see what its job needs.

Files in this zip

  • money_matrix_php.html, money_matrix_node.html — the role × money matrix for each version of the app
  • run_php.log, run_node.log — the raw test output
  • role_permissions.html — which role holds which money permission, read straight from each database
  • 12-money-matrix.spec.js, moneyMatrixSeed.js — the test itself (it stays in the code and can be re-run any time)
